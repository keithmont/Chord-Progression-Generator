# Find Your Voicing — Chord Machine

Pick a key and a progression and the app lays out six ways to play it on guitar, then plays it with recorded guitar samples. It runs entirely in the browser: no AI, no API key, no backend.

## How it works

- **Progressions** (`src/data/progressions.ts`): static banks of Roman-numeral progressions, one for major and one for minor (switch with Major / Minor under the key bank; in minor, degrees follow natural minor and case sets quality, so `V` is the harmonic dominant). Custom progressions are typed as numerals (`I vi ii7 V7`, `I bVII IV`, `Isus2 IV vi Vsus4`) and parsed by `src/lib/theory.ts`, which spells every chord correctly for the chosen key.
- **Voicings** (`src/data/voicings.json`): a static library generated by `scripts/build-voicings.ts`. For each of 12 roots × 20 chord qualities, it enumerates every playable fingering in standard tuning (4-fret span, ≤4 fingers or a barre plus 3) and files the best ones under six styles: Open, Barre, Power, Shell, Top-string triads and Twinkle extensions. Rebuild it with `npm run build:voicings` after changing the rules.
- **Voice leading** (`src/lib/voicings.ts`): each set picks the shape for each chord that keeps the fretting hand moving least. **Shuffle** rotates the starting shape.
- **Sound** (`src/lib/audio.ts`): a Web Audio sampler over real recordings (steel-string, nylon and electric) in `public/samples/`. Each string plays the nearest recorded note, repitched, with a per-string strum delay, string damping, a little humanising and a room reverb. The Tempo, Strum, Ring and Level knobs and the strum patterns (whole, halves, quarters, D DU UDU) drive it live.
- **Sequence**: press **Add** under any chord to build your own progression (up to 8 steps), drag to reorder, and loop it. Settings and the sequence are saved in the browser.

## Design

The UI follows the *Chord Machine* design system: a hardware-synth panel with key caps, knobs, an amber LCD and one hot orange key. Tokens live in `src/tokens.css`, generated from the design system's `tokens.json`. Chord function is colour-coded: blue for tonic, yellow for subdominant, orange for dominant. The numeral is always printed alongside the colour. There is a light *Panel* theme and a dark *Night* theme.

## Run locally

Prerequisites: Node.js 20+

```
npm install
npm run dev
```

`npm run build` makes a static site in `dist/` that can be deployed to any static host (e.g. Vercel).
